# Vending Machine Pickup Line

Entry for [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) on make.fun.

`main.py` (Python 3.13, standard library only, no network) writes one pickup
line — spoken by a vending machine to a passing human — to `/output/entry.txt`.

## The line

> Everybody else gets my sold-out light. You? I just restocked my heart.

70 characters. The machine's own world (its sold-out light, its restock), the
turn lands in the last few words, and it stays cheeky and warm rather than
creepy.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Every run writes byte-identical output.
